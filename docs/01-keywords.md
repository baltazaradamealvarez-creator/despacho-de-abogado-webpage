# 1. Investigación de palabras clave por página

**Regla:** una keyword principal por página. Ninguna página compite con otra por la misma búsqueda.
**Volúmenes:** [PENDIENTE] validar en Google Keyword Planner (ubicación: Nuevo León) y en Search Console del sitio actual antes de cerrar la lista. La prioridad de abajo es criterio de negocio (intención y valor del cliente), no volumen.

Intención: **L** = local (la persona busca un proveedor cerca), **C** = comercial (está comparando para contratar), **I** = informativa (está aprendiendo).

**Cómo se evita la canibalización**
- "Despacho contable" + **Monterrey** → Inicio. "Despacho contable" + **San Pedro** → Contacto (página con dirección, mapa y cómo llegar, que es lo que busca quien escribe la colonia o el municipio).
- "Contabilidad para empresas" (servicio) → página de Contabilidad. El Inicio no usa esa frase exacta en H1/H2.
- Las landing pages llevan `noindex`: no compiten con las páginas orgánicas.
- Los artículos del blog atacan búsquedas **informativas** ("qué es", "cuándo", "cómo") y enlazan a la página de servicio que corresponde. Nunca usan la keyword comercial de un servicio como keyword principal.
